12. Comparison: Kaktovik vs Ndebe Arithmetic

Shared advantages

  • Single glyphs for all values 0–19 — no multi-digit ambiguity
  • Visual structure reveals mathematical relationships
  • Carrying and borrowing follow consistent flag/body logic
  • Both extend naturally to vigesimal fractions

Key differences

Situation Kaktovik Ndebe
Borrowing Unfold v-shape into 5 lines — geometrically direct Flag Demotion — requires knowing flag sequence
Place Demotion 1 twenty = 4 v-shapes in units (20 = 4×5) 1 twenty = 15F0B + 5F0B in units
Division (flag contribution) Divisor pattern found rotated → write rotated numeral (×5) Divisor found in flag → contribute flag value
Division (body contribution) Divisor pattern found unrotated → write unrotated numeral Divisor found in body → contribute body value
General division Chunking with coloured pencils (illustrated problems chosen to work out easily) Ladder Method (§9.4) — works for every case
Zero Crossed arms — no counting, skip entirely Flag of 5 without body — same operational rule applies
