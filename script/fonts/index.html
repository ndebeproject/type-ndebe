Installation, verification & current limits

Open the TTF to install it. Select Ńdẹ́bẹ́ Rounded at weight 400 or Ńdẹ́bẹ́ Soft Bold at weight 700; each is a separate family with a Regular face. Installing a font does not change your keyboard mapping.

Both fonts passed representative TextEdit and Pages rendering checks on macOS, including native save/reopen. Physical Keyman input was confirmed in TextEdit. Windows, physical mobile input, Keyman entry in Pages, and embedded-font portability remain unverified. Editable-document embedding is enabled; this setting does not grant additional distribution or licensing rights.

Fonts and this catalogue use the approved release candidate. No editable font source files are included here.
