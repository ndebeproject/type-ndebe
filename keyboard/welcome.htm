Use

Install this package in Keyman, enable the keyboard, and select Ndebe Rounded or Ndebe Soft Bold in your document. No keyboard or font is installed by building the package.

Quotations

Native quotation alternation examines up to 64 preceding characters. When the previous quote is beyond the available context, it opens a quotation. Use Alt+apostrophe to insert a closing quote or flip the adjacent one. Single and double quotes are independent. This is a native keyboard limitation; the website examines the complete preceding text.

Teaching and equations

The Math, Currency, Teaching, and Symbols and spacing palettes belong to Type Ndebe; installing a keyboard does not put those panels inside other applications. Teaching text made in Type Ndebe can be copied into applications that support the installed fonts and OpenType shaping. Structured equations require compatible document formatting.
